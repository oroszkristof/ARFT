Projekt terv - H1

1. Webalkalmazás célja

Valós idejű adatokat biztosítson a részvényárfolyamokról, indexekről és más pénzügyi eszközökről, segítve a felhasználókat a tájékozott döntéshozatalban. Az emberek számára lehetőséget teremt, hogy kockázatmentesen gyakorolhatják a befektetési döntéshozatalt valós vagy historikus adatokkal. Az alkalmazás lehetőséget biztosíthat adatelemzésre, grafikonok és mutatók segítségével a piaci trendek vizsgálatára. Lehetőséget biztosít különböző befektetési stratégiák tesztelésére, például rövid és hosszú távú kereskedés kipróbálására. Valamint az átlag emberek is képesek megérteni a pénzügyi piacok működését és a gazdasági események hatását a részvényárfolyamokra. Továbbá segíti az embereket gazdasági elméletek gyakorlati alkalmazásában, például a portfóliókezelés vagy kockázatelemzés területén.

2. Csoport tagjai, struktúrája

A fejlesztői csoportunk két főből áll. Ketten készítjük el az alkalmazásunk dokumentációját, illetve a hozzá tartozó webalkalmazást. Orosz Kristóf aki főként a frontend fejlesztéseket és az UI/UX tervezéseket fogja végrehajtani. Radvánszky Ádám János pedig főként a Backend fejlesztéseket fogja elvégezni. Továbbá Ő fogja ellátni részben a projektmenedzseri feladatokat is.
A projekt fejlesztése közben mindketten tesztelőként is nyomonkövetjük alkalmazásunk fejlesztését, a weboldalunk megfelelő működése érdekében, amely során tapasztalatainkat, ötleteinket majd átadjuk egymásnak.

FELADATMEGOSZTÁS

Döntök az alkalmazás navigációs struktúrájáról és az interakciós mintákról. Készítek a wireframe-eket, prototípusokat és az UI mockupokat. Elvégzem az elsődleges felhasználói teszteket. 4. Programozói nyelvek, fejlesztő eszközök

HTML A weboldal struktúrájának kialakításához.
CSS A vizuális megjelenés és reszponzivitás biztosítására. (normál CSS és Bootstrap)
JavaScript A dinamikus funkcionalitások (pl. adatlekérdezés, grafikonok frissítése) programozásához.
API-k Külső tőzsdei adatforrások integrálására (pl. Alpha Vantage API), valamint a mesterséges inteligencia integrálása.
ASP.NET Core MVC Segítségével elkészítjük a dinamikus webalkalmazásunkat. Ahol a frontend HTML, CSS és JavaScript leírónyelvekkel valósul meg, míg a backend fejlesztése, C# és OOP alapelvek segítségével valósul meg. Az adatkezeléshez integrálható különböző adatbázisokkal, biztosítva a hatékony és biztonságos adatműveleteket.
FEJLESZTŐ ESZKÖZÖK Visual Studio 2022 (kódszerkesztés) valamint Visual Studio Code (kódszerkesztés), Git (verziókezelés)


5. Használni tervezett eszközök, technikák

A weboldal fejlesztéséhez modern webfejlesztési technikákat és eszközöket alkalmazunk. A reszponzív dizájn érdekében CSS keretrendszert (Bootstrap) használunk, hogy az oldal minden eszközön jól működjön. Az adatok dinamikus megjelenítéséhez JavaScriptet és annak könyvtárait a Chart.js a grafikonokhoz tervezzük bevetni.
A tőzsdei adatok lekérdezéséhez REST API-kat integrálunk, amelyeket aszinkron módon kezelünk (pl. Fetch API vagy Axios). A verziókezeléshez Git-et használunk, a kód szerkesztéséhez pedig Visual Studio Code-ot, amely kényelmes debuggolási és kiegészítő lehetőségeket biztosít.

7. Tesztelési követelmények

A tőzsdei webalkalmazásunk esetében a dokumentáció részletesen meghatározza a valós idejű adatáramlás, a tranzakciók integritása és a biztonsági protokollok tesztelésének módszereit. Ebben a dokumentumban szerepelnek az egység-, integrációs, rendszer- és felhasználói elfogadási tesztek, továbbá a hibakezelési és teljesítménytesztelési kritériumok. A tesztelési környezet kialakítása során olyan valós idejű adatforrásokat és szimulált piaci környezetet használunk, amely megfelelően modellezi a tőzsdei működést és a gyors piaci mozgásokat. Fontosnak tartjuk a biztonsági követelmények teljesítéséhez szükséges a rendszer folyamatos sérülékenység-vizsgálatának elvégzését, például behatolási tesztek formájában.


8. Bemutatás (demó) és szállítás módja, ideje

A weboldal bemutatását egy működő demó formájában tervezzük megvalósítani. A demót egy helyi szerveren futtatva a prezentáció során, de opcionálisan egy hosting szolgáltatáson is elérhetővé tesszük, hogy az oktatónk és hallgatótársak online is megtekinthessék. A szállítás módja egy zip fájl lesz, amely tartalmazza a forráskódot, a dokumentációt és egy rövid telepítési/use-case útmutatót.
A demó során bemutatjuk a fő funkcionalitásokat, mint például az árfolyamok valós idejű megjelenítését és a felhasználói felület kezelhetőségét.
